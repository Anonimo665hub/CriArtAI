CRIART AI - PROJETO ANDROID INICIAL

O que esta versão contém:
- Aplicativo Android com interface CriArt AI.
- Abas para imagens, desenhos e músicas.
- Campos para descrever criações e escolher estilos.
- Funciona como protótipo local dentro de um WebView.

IMPORTANTE:
Esta versão ainda NÃO gera imagens ou músicas de verdade.
Para isso, é necessário integrar um serviço de IA por meio de um backend seguro.
Não coloque chaves secretas/API diretamente no APK.

COMO GERAR O APK:
1. Instale o Android Studio em um computador.
2. Extraia esta pasta ZIP.
3. No Android Studio, escolha Open e selecione a pasta CriArtAI_Android.
4. Aguarde a sincronização do Gradle.
5. Abra Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Quando terminar, use o link "locate" exibido pelo Android Studio.
7. Copie o APK para o celular Android e instale.

Requisitos:
- Android Studio recente.
- JDK 17 (normalmente incluído no Android Studio).
- Internet para baixar as ferramentas de compilação.

O APK não foi compilado neste ambiente porque não há Android SDK/Gradle instalado.
